🏦 Banking System Web
A simple banking interface built with HTML, and JavaScript, DOM. The project provides a dashboard to enter deposit and withdrawal amounts and view the deposit total, withdrawal total, and available balance.

✨ Features
- 💰 Deposit amount section
- 💸 Withdrawal amount section
- 🧮 Balance / amount display
- ➕ Deposit input and action button
- ➖ Withdrawal input and action button
- 📊 Separate display for deposits, withdrawals, and balance
- 🎨 Clean and simple user interface
🛠️ Technologies Used
- HTML5 — Page structure
- CSS3 — Layout and styling
- JavaScript — Banking calculations and interface interaction
⚙️ How to Use
1. Open the live website.
2. Enter an amount in the Deposit input field.
3. Click Add Deposit to submit the deposit.
4. Enter an amount in the Withdraw input field.
5. Click Add Withdraw to submit the withdrawal.
6. Check the dashboard to view the displayed deposit, withdrawal, and balance amounts.
🎯 Project Purpose
This project was created to practice building an interactive web interface and applying JavaScript to a basic banking-style calculation workflow.
📚 Concepts Practiced
- HTML form inputs and buttons
- CSS layout and styling
- JavaScript event handling
- Reading input values
- Number conversion and arithmetic
- Updating page content through the DOM
